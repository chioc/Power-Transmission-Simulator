# ⑦まとめ課題の提出を使うための準備（先生向け）

生徒がアプリから提出した内容を、先生のスプレッドシートにためるための準備です。最初に1回だけ行います（30分ほど）。

> **大事な前提**：提出者のメールアドレスを自動で取得できるのは、**GAS プロジェクトの持ち主と生徒が、同じ学校の Google Workspace アカウント**を使っているときだけです。個人の Gmail で作った GAS プロジェクトでは取得できません。

---

## 手順0　GAS プロジェクトの持ち主を確認する

1. script.google.com で、このアプリのプロジェクトを開く
2. 右上の丸いアイコンを押し、表示されるメールアドレスの末尾を確認する
   - **学校のドメイン**（例：`@〇〇.ed.jp`）なら → 手順1へ
   - **`@gmail.com`** なら → 下の「学校アカウントへの引っ越し」を先に行う

### 学校アカウントへの引っ越し（個人の Gmail で作っていた場合だけ）

1. **学校のアカウント**で script.google.com を開き、「新しいプロジェクト」を作る
2. その新しいプロジェクトのスクリプトIDを写す（左の歯車「プロジェクトの設定」）
3. **学校のアカウント**で script.google.com/home/usersettings を開き、「Google Apps Script API」をオンにする
   - オンにできない場合は、学校の管理者に相談してください
4. GitHub でリポジトリの `.clasp.json` を開き、鉛筆アイコンで編集する。`scriptId` を新しいIDに書き換え、「Commit changes」を押す
5. README の手順で、**学校のアカウント**で clasp にログインし、`CLASPRC_JSON` を作り直して GitHub の Secrets を上書きする
6. GitHub の「Actions」タブ →「GASへ反映（テスト用 /dev）」→「Run workflow」で、新しいプロジェクトにプログラムを送る

## 手順1　提出先のスプレッドシートを作る

1. **学校のアカウント**で Google ドライブを開き、「新規」→「Google スプレッドシート」を選ぶ
2. 名前を「動力伝達シミュレーター 提出先」などにする
3. ブラウザのアドレス欄から、**スプレッドシートのID**を写す
   - `https://docs.google.com/spreadsheets/d/`**ここの長い英数字**`/edit...`
4. このスプレッドシートは、**生徒と共有しないでください**。生徒が見たり書いたりする権限がなくても、アプリから提出できます

## 手順2　ID を GAS に登録する（スクリプトプロパティ）

1. GAS のエディタで、左の**歯車のアイコン（プロジェクトの設定）**を押す
2. 下のほうの「**スクリプト プロパティ**」→「**スクリプト プロパティを追加**」を押す
3. 次のように入力して「**スクリプト プロパティを保存**」を押す
   - プロパティ：`SPREADSHEET_ID`
   - 値：手順1で写したID

ID をプログラムに直接書かないのは、プログラムを GitHub で公開してもスプレッドシートの場所が分からないようにするためです。

## 手順3　シートを準備する（setupSheets を実行）

1. GAS のエディタで、左のファイル一覧から「**Code.gs**」を開く
2. 上の「実行」ボタンの右にある関数の選択欄で、「**setupSheets**」を選ぶ
3. 「**実行**」を押す
4. 初回は「承認が必要です」と出るので、次の順に進める
   1. 「権限を確認」
   2. 学校のアカウントを選ぶ
   3. 内容を確認して「許可」
   - アプリが求める権限は「スプレッドシートの編集」と「メールアドレスの確認」の2つです
5. 下の「実行ログ」に「**準備ができました**」と出れば完了

スプレッドシートを開くと、「**名簿**」と「**提出データ**」の2つのシートができ、1行目に見出しが入っています。

## 手順4　名簿を入力する

「名簿」シートの2行目から、生徒1人につき1行ずつ入力します。

| クラスコード | 名簿番号 | メールアドレス |
|---|---|---|
| 201 | 1 | 生徒の学校アカウントのメールアドレス |
| 201 | 2 | … |

- クラスコードは `201`〜`204` のどれか
- 同じ「クラスコードと名簿番号」の組や、同じメールアドレスを2行に入れないでください。重複があると、その生徒は提出できません
- 1行目の見出しは変えないでください。列の順番は入れ替えても動きます
- 名簿や提出データは、このスプレッドシートの中だけに置いてください。GitHub や AI との会話には貼り付けないでください

「提出データ」シートは、生徒が提出すると自動で行が増えます。右側に「評価メモ」などの列を自由に足しても、再提出で消えることはありません。

## 手順5　生徒用の URL を作る（デプロイ）

テスト用 URL（末尾 `/dev`）は、**GAS の編集権限がある人しか開けません**。生徒や生徒用テストアカウントは、本番用 URL（末尾 `/exec`）で開きます。

1. GAS のエディタで「**デプロイ**」→「**新しいデプロイ**」を押す
2. 歯車のアイコンから「**ウェブアプリ**」を選ぶ
3. 次のようになっていることを確認して「**デプロイ**」を押す
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**（学校名）内の全員**
4. 表示された「**ウェブアプリの URL**」（末尾 `/exec`）を写す。これが生徒に配る URL です
5. 同じ画面の「**デプロイ ID**」を写し、GitHub の Settings → Secrets and variables → Actions に、`GAS_DEPLOYMENT_ID` という名前で登録する
   - 以後、GitHub の「Actions」→「本番デプロイ（手動）」→「Run workflow」を押すと、生徒用 URL を変えずに中身を最新にできます

## 手順6　生徒用テストアカウントで確かめる（配布の前に必ず）

1. 学校の管理者に、**先生とは別の、学校内の生徒用テストアカウント**を用意してもらう
2. 名簿に、テストアカウントを架空の番号で登録する（例：`204`・`40`）
3. ブラウザのシークレットウィンドウでテストアカウントにログインし、手順5の `/exec` の URL を開く
4. ⑦まとめ課題で、すべて入力して「提出する」を押す
5. 「提出しました」と出て、「提出データ」シートに1行増えれば成功
6. 確かめ終わったら、名簿と提出データからテストアカウントの行を消す

## うまくいかないとき

| 生徒の画面に出るメッセージ | 考えられる原因と対処 |
|---|---|
| 学校アカウントで開いているか確認してください | メールアドレスを取得できていません。生徒が学校のアカウントで開いているか、デプロイが「自分として実行」「（学校名）内の全員」になっているか、GAS の持ち主が学校のアカウントかを確認してください |
| クラスコード・名簿番号・学校アカウントを確認してください | 入力したクラスコード・名簿番号の行のメールアドレスが、開いている人のアカウントと一致しません。名簿の入力ミスや重複も確認してください |
| 提出先の準備ができていないため、保存できませんでした | 手順2の `SPREADSHEET_ID` が正しいか、「名簿」「提出データ」シートと見出しがあるかを確認してください（手順3をもう一度実行すると確認できます） |
| 提出データに同じアカウントの行が複数ある | 「提出データ」シートで、同じメールアドレスの行を1つにまとめてください |
| ほかの人の提出が重なっています | 少し待ってから、もう一度「提出する」を押すよう伝えてください |
