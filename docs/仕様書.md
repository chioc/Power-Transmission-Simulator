# 動力伝達・運動変換シミュレーター 仕様書

最終更新：2026-11-12
状態：初版の実装依頼案

## 1. 目的・対象

- 対象学年・単元：中学校第2学年、技術分野 C エネルギー変換の技術「動力伝達の仕組みと問題解決（仮）」。4時間を想定。
- 授業での目的：モーターの回転が、機構を通してどのような向き・速さ・トルク・動き方として出力されるかを観察・説明し、目的に合う機構を選び、試行結果をもとに調整する。
- 授業での使い方：1時間目は回転方向と平歯車の実験、2時間目は速度伝達比の計算と条件に合う歯車の選択、3時間目はリンク・カムとラックの比較、4時間目は機構を選び調整する課題。各時間の範囲内で生徒が自分のペースで進む。

## 2. 指導要領・評価との対応

## 3. 機能一覧と画面の流れ

| No | 機能 | 利用者 | 概要 |
|---|---|---|---|
| 0 | ホーム | 生徒／教員 | 「回転を伝える」「回転を別の運動に変える」「まとめ課題」への入口を表示する |
| 1 | 回転の伝わり方 | 生徒 | 平歯車を2枚または中間歯車を含む3枚で動かし、回転方向を比較する。固定構成の機構一覧へ移動できる |
| 2 | 平歯車の速さとトルク | 生徒 | 入力・出力の歯数を変え、出力回転数と理想トルクの変化を比較する |
| 3 | 速度伝達比の計算 | 生徒 | 直前の平歯車設定を使って、速度伝達比と出力回転数を計算し、答えを入力して確かめる |
| 4 | リンクの実験 | 生徒 | クランク・スライダとクランク・揺動レバーを切り替え、入力クランクの半径を変更して出力の運動と範囲を比べる。ラックとピニオンの観察画面にも移動できる |
| 5 | カムの実験 | 生徒 | カムの形状を切り替え、従動節が動く区間、移動量、位置を保つ区間を観察する |
| 6 | 教科書の機構を見る | 生徒 | 下表の7機構を固定構成で一つずつ動かす |
| 7 | まとめ課題 | 生徒 | 課題を選び、機構を試し、選択・試行・調整の理由を記述する |

**画面の流れ**

- 回転を伝えるコース：①回転の伝わり方 → ②速さとトルク ↔ ③計算。
- 回転を別の運動に変えるコース：④リンク、⑤カム。両方にホームから直接進める。
- 機構一覧とまとめ課題もホームから直接開ける。学習画面には前後の画面またはホームに戻る操作を置く。確認問題の正答や機構一覧の閲覧状況にかかわらず移動できる。

**共通操作と表示**

- 動作画面は初期状態で停止。再生、一時停止、低速再生、入力軸の手動操作、初期位置に戻す操作を用意する。手動操作はスライダー等で途中の角度に止められるようにし、角度の操作に合わせて出力を更新する。
- 入力と出力を色と文字ラベルで区別する。回転には向きの矢印、直線運動には移動方向、揺動には角度の変化を示す。観察用の再生速度を変えても、計算上の回転数や伝達比は同じ値を示す。
- 学習画面①〜⑤は「予想 → 操作 → 確認」の流れをそろえ、短い確認問題を各画面に1問置く。結果を見た後も設定を変更し、再回答できる。
- 学校のiPadのタッチ操作とPCのマウス操作を想定する。ボタンとスライダーはタッチで扱え、図・ラベル・操作部が重ならないようにする。

**平歯車の実験と計算**

- 外歯の平歯車を使用する。入力・出力の歯数は各20歯・40歯から選べる。中間歯車は1枚の着脱式とし、初版では20歯固定。各歯車の軸は独立し、中間歯車は前後の歯車とかみ合う。
- 計算例の入力軸は60回転/分、入力トルクは1 N·m。出力回転数は速さの大きさで表示し、方向は別に示す。
- 速度伝達比 ＝ 出力回転数 ÷ 入力回転数 ＝ 入力歯数 ÷ 出力歯数。教科書との用語照合が済むまで、この定義を画面に明記し、「ギア比」単独の数値ラベルは使わない。
- 出力回転数 ＝ 入力回転数 × 速度伝達比。理想出力トルク ＝ 入力トルク ÷ 速度伝達比。トルク表示には「損失を無視した理想値」と添える。
- ②と③の間で歯数・中間歯車の設定を引き継ぐ。③の出題中は問題欄で答えを伏せ、確認後に式・数値・単位を表示する。誤答時は入力と出力のどちらを分子にするかをヒントに示し、再入力できる。

**固定構成の観察**

| 機構 | 表示する動作と観察の問い |
|---|---|
| 傘歯車 | 直交する2軸を見分けられる図で回転。入力軸と出力軸はどのような角度で交わるか |
| ウォームギア | 1条のウォームが1回転するとホイールが1歯分進む。どの部品が入力側か |
| 摩擦車 | 接触した2輪が滑りなしのモデルで逆方向に回転。接触部で動きはどう伝わるか |
| ベルトとプーリ | 交差しないベルトを使い、離れた2軸が同方向に回転。ベルトのどの部分が動力を伝えるか |
| 歯つきベルトと歯つきプーリ | ベルトの歯とプーリの歯がかみ合って進む。どこでかみ合うか |
| チェーンとスプロケット | チェーンのリンクとスプロケットの歯がかみ合って進む。歯はどこに入るか |
| ラックとピニオン | 回転方向に応じてラックが直線移動する。端で停止し、手動で逆方向に回すと戻る。クランク・スライダの往復と何が違うか |

固定構成は部品追加・組替え・歯数変更の操作を省き、再生・停止・低速・手動操作を提供する。ラックは一覧と④から同じ観察画面を開く。ラックの移動端では連続再生を停止する。

**リンク・カムとまとめ課題**

- リンク：入力軸が連続1回転できるように組んだ2種類の機構を用意する。各機構に「小」「大」のクランク半径を用意し、1回転中のスライダの移動範囲またはレバーの揺動範囲を比較できるようにする。
- カム：「従動節が連続的に上下する形」と「従動節が一定位置にとどまる区間がある形」の2種類を用意する。同じ再生条件で比較し、入力角度と従動節位置の変化を図で追えるようにする。
- まとめ課題は「モーターを回し続けて、部品を一定の間隔で押し出す」「モーターを回し続けて、アームを左右に振る」の2題。生徒は機構と設定を選び、試してから「選んだ機構と理由」「試して分かったこと」「調整した点と理由」を記入する。教員が動きと説明を確認する。正解の機構を一つに固定して自動採点する機能は初版の範囲外。
